# Code of conduct

**English** · [Русский](CODE_OF_CONDUCT.ru.md)

Ejix welcomes contributors with different backgrounds and experience levels. Be respectful, discuss the work with evidence, and make room for questions and disagreement.

Harassment, threats, discriminatory abuse, personal attacks, deliberate disclosure of private information and repeated disruption are unacceptable. Critique code and decisions, not people. Respect model ownership and the confidentiality of shared material.

Maintainers may edit or remove inappropriate content, close a discussion, or restrict participation when needed. Actions should be proportionate and consider the context. Report conduct concerns privately to a maintainer using an available repository contact. If no private contact is available, request one without naming affected people or exposing private details publicly. Maintainers with a conflict of interest should defer handling to another available maintainer.

These expectations apply in project-managed issues, pull requests and discussions, and when representing the project. Contributions remain subject to the [license](LICENSE).
