# Changelog

[Русский](CHANGELOG.ru.md)

## 1.0.0

- Extract volumes defined by closed sketch profiles and planar faces from one or more solid bodies.
- Use profiles on different planes and choose separate results or a combined result for connected regions.
- Preview intersections before confirming and choose which source bodies participate.
- Configure distance, direction, start, target, and result options using Fusion controls.
- Create an editable Eject Feature or a group of native Fusion features.
- Create bodies or components and optionally subtract results from the source bodies.

See the [user guide](docs/GUIDE.md) for supported geometry and limitations.
