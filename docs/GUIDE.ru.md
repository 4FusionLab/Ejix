# Руководство пользователя

## Извлечь область

Eject отделяет пересекающийся объём в новое тело без перемещения в пространстве. Текущая реализация создаёт штатные Copy, Extrude Intersect и Combine Cut.

1. Откройте параметрическую модель и запустите **Eject** через Solid → Modify или поиск команд.
2. Выберите замкнутые **Profiles** эскиза или плоские грани, в том числе на разных плоскостях.
3. Пересекаемые тела появятся в **Objects to Eject** автоматически. Снимите флажки с ненужных тел. Список обновляется при изменении протяжённости и сохраняет исключения.
4. Задайте направление и протяжённость. Потяните стрелку или введите выражение, например `Width / 2`.
5. Выберите тип таймлайна и результата. Проверьте **Preview**, нажмите **OK**. **Cancel / Esc** отменяет команду.

## Направление и протяжённость

| Настройка | Значение |
| --- | --- |
| One Side | Одно направление; перетащите стрелку через ноль или используйте Flip для противоположного направления |
| Two Sides | Два независимых расстояния и две стрелки |
| Symmetric | Одинаковая длина с каждой стороны; Distance означает Half Length |
| Distance | Длина или выражение длины; в One Side отрицательное значение меняет направление |
| To Object | До плоской грани или конструкционной плоскости; две независимые цели и смещения для Two Sides |
| All | Через всё в выбранных направлениях; стрелки длины скрыты |
| Start: Profile Plane | Начало на плоскости профиля, по умолчанию |
| Start: Offset | Начало со знаковым смещением вдоль нормали профиля |
| Start: Object | Начало от параллельной плоской грани или конструкционной плоскости; смещение вдоль нормали выбранного объекта |

Каждая плоскость использует своё локальное направление, общие настройки глубины и Flip. Objects принадлежат тому же компоненту и экземпляру. При включённом Subtract плоскости обрабатываются в порядке выбора: пересечение остаётся в результате первой плоскости, следующая работает с остатком тела. Без Subtract каждый профиль извлекает полное пересечение с исходным телом. Оба типа таймлайна поддерживают разные плоскости.

## Одна область, несколько тел

Ejix автоматически находит видимые пересекаемые тела исходного компонента и экземпляра. После OK извлечение из включённых тел выполняется до первого вычитания. Результаты разных оригиналов не объединяются; наложенные тела сохраняют независимые результаты. Тела без объёмного пересечения не попадают в автоматический список.

## Настройки результата

| Поле | По умолчанию | Действие |
| --- | --- | --- |
| Timeline | Eject Feature | Собственная фича Eject или редактируемые штатные операции Copy / Intersect / Cut |
| Operation | New Body | Результаты остаются в исходном компоненте |
| Subtract from Objects | Включено | Извлечённый объём вычитается из своего оригинала |
| Preview | Включено | Отрисовка временных пересечений без создания тел и узлов таймлайна |

При выборе нескольких профилей появляется **Profile Results**:

- **Separate Bodies** — отдельный результат каждого профиля. При включённом вычитании профили обрабатываются по порядку выбора; пересекающаяся часть принадлежит первому результату.
- **Combine Connected** — пересекающиеся и касающиеся объёмы одного исходного тела объединяются, затем вычитаются одним действием. Несвязанные объёмы остаются отдельными телами; результаты разных исходных тел не объединяются.

В Eject Feature этот выбор фиксируется при создании. Для изменения способа объединения нужно пересоздать фичу.

**New Component** создаёт дочерний компонент для каждого результирующего тела. Если Intersect вернул несколько тел, сохраняются все. При выключенном вычитании сохраняются оригиналы и их пересекающиеся копии.

**Eject Feature** объединяет ту же нативную цепочку в собственный узел. **Edit Eject** меняет направление, протяжённость и смещение на месте. Источники, Operation и Subtract фиксируются при создании; для их изменения операцию нужно пересоздать. Параметры принадлежат штатным операциям, отдельного дублирующего набора нет.

При редактировании Eject Feature изменение пересечений между плоскостями и телами может потребовать пересоздания операции. Для New Component переносы результатов находятся в таймлайне после узла Eject; изменение участия полностью охваченного тела также требует пересоздания.

## Превью и история

Preview вычисляет временные BRep-пересечения и показывает золотой полупрозрачный объём; без вычитания используется синий цвет. Тела модели, компоненты и операции при этом не создаются. OK убирает подсветку и создаёт результат, Cancel убирает подсветку. В Edit используется такой же предпросмотр, а таймлайн меняется после подтверждения.

## Ограничения

- Требуется Capture Design History. Direct Modeling не поддерживается.
- Источники — замкнутые профили и плоские грани. Start Object требует параллельную плоскость для каждого профиля; начальная грань должна вмещать проекцию профиля, как требует Fusion.
- Источники и Objects принадлежат одному компоненту и assembly context.
- Автоматический поиск ограничен видимыми твёрдыми телами исходного компонента и экземпляра.
- При включённом Subtract полностью охваченные тела пропускаются, остальные продолжают участвовать. Пропущенные тела не подсвечиваются и не копируются. При выключенном Subtract полные копии разрешены.
- To Object поддерживает плоские грани и конструкционные плоскости, но не криволинейные цели и Symmetric. Нет Taper Angle и разделения несвязных lumps внутри одного BRepBody.
- Eject Feature использует Fusion Custom Feature API, который Autodesk относит к Preview.
