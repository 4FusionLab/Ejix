# Контракт интерфейса

[English](UX.md) · **Русский** · [Главная](../README.ru.md)

## Нативное взаимодействие

Ориентир — Extrude / Cut / Intersect: стандартные CommandInputs, родные иконки, стрелки расстояния и выражения, To Object и автоматический список участников. Eject отделяет объём без перемещения в пространстве.

Direction, Extent Type и Operation используют LabeledIconDropDownStyle с графикой из текущей установки Fusion. Flip использует нативную иконку направления. Ресурсы Autodesk не копируются в дистрибутив; если ресурс отсутствует, остаётся текстовая подпись.

## Поля

| Поле | Поведение |
| --- | --- |
| Profiles | Замкнутые профили или плоские грани, в том числе на разных плоскостях |
| Direction | One Side / Two Sides / Symmetric с нативными иконками |
| Flip Direction | Кнопка с родной иконкой для One Side |
| Extent Type | Distance / To Object / All с нативными иконками |
| Object / Object 2 | Плоская грань или конструкционная плоскость для каждого направления To Object |
| Distance / Distance 2 | Штатные стрелки и поля выражений |
| Offset / Offset 2 | Подписанное смещение цели To Object |
| Start: Profile Plane / Offset / Object | Подписанное смещение плоскости Profiles |
| Timeline | Eject Feature (по умолчанию) / Native Features |
| Operation | New Body / New Component с родными иконками |
| Profile Results | Separate Bodies / Combine Connected; показывается для нескольких профилей |
| Objects to Eject | Автоматически найденные тела с флажками участия |
| Subtract from Objects | Включено по умолчанию |
| Preview | Включено по умолчанию |

Symmetric использует Half Length и Distance / All. To Object поддерживает One Side и Two Sides. Если выбрать Symmetric при активном To Object, Extent Type возвращается в Distance.

Если Profile принадлежит скетчу, построенному на твёрдой грани, One Side по умолчанию направлен внутрь материала этой грани, независимо от направления Z скетча. Flip разворачивает его. Профиль на конструкционной плоскости сохраняет направление плоскости.

## Поиск тел

Выполняются временные пересечения с видимыми твёрдыми телами исходного компонента и экземпляра. Тела с положительным объёмом пересечения автоматически попадают в список и по умолчанию включены. Исключения сохраняются по идентичности тела при изменении протяжённости, включая временный выход тела из области и возвращение. Тела вне списка и выключенные участники не меняются.

## Превью — только графика

Preview не создаёт эскизы, BRep-тела модели, компоненты, Copy / Extrude / Combine и не перемещает маркер таймлайна. Видимость и appearance оригиналов не меняются. Используются точные временные BRep-данные и невыбираемая Custom Graphics: золотая полупрозрачная область вычитания либо синяя область при сохранении оригиналов, видимая сквозь исходные тела.

Перетягивание обновляет временные пересечения и список участников. Манипулятор не переустанавливается во время drag расстояния. Во время drag источником истины является актуальное `DistanceValueCommandInput.value`, потому что Fusion оставляет `.expression` устаревшим; совпадающие выражения сохраняются, чтобы не терять параметры. Ноль принимается полем только для доставки изменения: он очищает превью, а проверка не даёт нажать OK до ввода положительного расстояния. executePreview всегда оставляет isValidResult=False: графика не является результатом моделирования, который Fusion может принять вместо execute.

OK убирает графику, повторно разрешает включённые тела и цели и один раз выполняет нативное построение. Cancel / Esc только убирает подсветку. Ошибка окончательного построения отменяет транзакцию через executeFailed. В Edit тоже используется графическое preview; изменения таймлайна происходят только после подтверждения.
