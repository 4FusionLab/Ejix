# Процесс выпуска

[English](PUBLISHING.md) · **Русский**

CI проверяет метаданные репозитория, тесты, компиляцию Python и воспроизводимость пакетов на Linux, macOS и Windows. Нативные проверки Fusion выполняются отдельно.

Для подготовки релиза обновите версию в манифесте, историю изменений и примечания к выпуску на английском и русском языках. Проверьте контрольную сумму runtime и заполните результаты проверки платформ и API в `release/acceptance.json`.

Запустите workflow **Publish release** из основной ветки с соответствующим тегом и типом выпуска. Workflow выполняет CI, проверяет версию, собирает архивы исходников и дополнения с SHA-256 и публикует релиз для проверенного коммита. Стабильный выпуск требует прохождения проверки нативной CAD-приёмки и API; предварительный выпуск помечается как prerelease.

Проверьте опубликованные тег, примечания, архивы и контрольные суммы. Порядок установки описан в [инструкции](INSTALLATION.ru.md).
