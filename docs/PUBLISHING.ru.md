# Процесс выпуска

[English](PUBLISHING.md) · **Русский**

CI проверяет метаданные репозитория, тесты, компиляцию Python и воспроизводимость пакетов на Linux, macOS и Windows. Нативные проверки Fusion выполняются отдельно.

Для подготовки релиза вычислите версию через GitVersion 6.8.2, обновите историю изменений и примечания к выпуску на английском и русском языках. При упаковке числовая версия GitVersion записывается в манифест внутри ZIP без изменения манифеста в репозитории. Проверьте контрольную сумму runtime и заполните результаты проверки платформ и API в `release/acceptance.json`.

Запустите workflow **Publish release** из основной ветки с соответствующим тегом (`vX.Y.Z` для stable или `vX.Y.Z-IDENTIFIER` для prerelease) и типом выпуска. Workflow выполняет CI, проверяет версию, собирает архивы исходников и дополнения с SHA-256 и публикует релиз для проверенного коммита. Для стабильного выпуска нужны результаты нативной CAD-приёмки и проверки API либо явно зафиксированные ограничения. Частично проверенные и непроверенные платформы остаются помечены соответственно. Предварительный выпуск помечается как prerelease.

Проверьте опубликованные тег, примечания, архивы и контрольные суммы. Порядок установки описан в [инструкции](INSTALLATION.ru.md).
