# Ejix 1.1.0

Fusion показывает **Pavel Kuznetsov** в поле автора. Владелец репозитория GitHub и издатель в Marketplace — **4FusionLab**.

Это стабильный выпуск серии 1.1.0. В нём действует лицензия PolyForm Noncommercial 1.0.0, которая уже входила в предварительные выпуски 1.1.0.

В Fusion на macOS прошли сценарии извлечения, редактирования Feature и повторного открытия локального F3D. Статус проверки Windows и ограничения Autodesk Custom Feature API приведены в [заметках о совместимости](../../release/limitations.md).
