# Ejix 1.0.0

Извлекайте объёмы из твёрдых тел Autodesk Fusion по профилям эскиза или плоским граням. Ejix показывает предпросмотр, автоматически находит исходные тела и предлагает настройки результата.

## Возможности

- Несколько областей на одной или разных плоскостях.
- Отдельные результаты в порядке выбора или объединение пересекающихся и касающихся областей одного тела.
- Результаты в виде тел или компонентов с необязательным вычитанием из оригиналов.
- Собственная Eject Feature или штатные операции Fusion; протяжённость Distance, To Object и All.
- Редактирование направления, протяжённости и начала Eject Feature.

## Требования и ограничения

Требуется Autodesk Fusion, рабочая область Design и включённая Capture Design History. Профили и участвующие тела должны принадлежать одному компоненту и экземпляру. To Object поддерживает плоские грани и конструкционные плоскости. Полностью охваченные тела пропускаются при включённом вычитании.

Eject Feature использует [Custom Feature API](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/CustomFeatures_UM.htm), который Autodesk относит к Preview и не рекомендует использовать в распространяемых производственных программах. Будущие изменения Fusion могут повлиять на эти фичи. Для моделей с ними сохраняйте установленную версию Ejix. Нативные проверки Fusion на macOS частичные; полная интерактивная приёмка не завершена. Нативная приёмка Fusion на Windows не проводилась.

## Установка

Скачайте `Ejix-1.0.0.zip`, распакуйте в постоянную папку и добавьте каталог `Ejix` через **Utilities → Scripts and Add-Ins** в Fusion. Целостность архива можно проверить по файлу SHA-256.
