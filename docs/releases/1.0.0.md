# Ejix 1.0.0

Extract volumes from solid bodies in Autodesk Fusion using sketch profiles or planar faces. Ejix provides an exact preview, automatic source-body discovery and editable result options.

## Highlights

- Extract several regions on the same or different planes.
- Keep regions separate in selection order, or combine intersecting and touching regions from the same source.
- Create bodies or components, with optional subtraction from the originals.
- Use an Eject Feature or native Fusion operations, with Distance, To Object and All extents.
- Edit Eject Feature direction, extent and start settings.

## Requirements and limits

Use Autodesk Fusion in the Design workspace with Capture Design History enabled. Profiles and participating bodies must belong to the same component and occurrence. To Object supports planar faces and construction planes. Fully enclosed bodies are skipped when subtraction is enabled.

Eject Feature depends on Autodesk's [Custom Feature API](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/CustomFeatures_UM.htm), which is currently designated Preview. Keep Ejix installed for designs containing its custom features. Native Fusion checks have been performed on macOS; native Fusion acceptance on Windows has not been completed.

## Install

Download `Ejix-1.0.0.zip`, extract it to a permanent folder and add its `Ejix` directory through Fusion's **Utilities → Scripts and Add-Ins**. The corresponding SHA-256 file can be used to verify the archive.
