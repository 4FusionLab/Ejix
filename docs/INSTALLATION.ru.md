# Установка и обновление

[English](INSTALLATION.md) · **Русский** · [Главная](../README.ru.md)

## Установка

1. Скачайте архив дополнения из [релизов Ejix](https://github.com/4FusionLab/Ejix/releases). Отдельный файл `.sha256` позволяет проверить архив.
2. Распакуйте архив в постоянную папку. Найдите каталог `Ejix` с файлами `Ejix.py` и `Ejix.manifest`.
3. В Fusion откройте **Utilities → Scripts and Add-Ins**. На вкладке **Add-Ins** нажмите **+** и добавьте каталог `Ejix`.
4. Выберите **Ejix** и нажмите **Run**. Включите **Run on Startup**, если хотите запускать дополнение автоматически.
5. Откройте модель с включённой Capture Design History и выберите **Design → Solid → Modify → Eject**.

Не перемещайте распакованную папку: Fusion загружает дополнение из неё. Отдельная установка Python или сторонних пакетов не требуется.

## Обновление

Завершите активную команду Eject, остановите дополнение в **Scripts and Add-Ins** и замените каталог `Ejix` целиком новой версией. Затем снова запустите Ejix. Простая замена файлов не обновляет работающий аддин.

## Удаление

Остановите Ejix и удалите его запись из **Scripts and Add-Ins**, затем удалите распакованную папку. Для редактирования и пересчёта моделей с Eject Feature требуется совместимая установленная версия Ejix.

## Сборка из исходников

```sh
python -m unittest discover -s tests -v
python scripts/check_project.py
python scripts/build.py --kind addin --channel release
```

Скрипт создаёт архив дополнения и контрольную сумму SHA-256 в `dist/`. Решение распространённых проблем — в разделе [Поддержка](../SUPPORT.ru.md).
