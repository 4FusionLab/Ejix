# Совместимость и проверки

Eject Feature использует [Custom Feature API](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/CustomFeatures_UM.htm) Autodesk Fusion. Autodesk относит этот API к Preview и не рекомендует выпускать производственные программы, зависящие от Preview API. Изменения Fusion в будущем могут повлиять на создание, редактирование или пересчёт Eject Feature. Для моделей с такими фичами сохраняйте доступ к совместимой версии Ejix.

Код проверен в Fusion 2706.1.14 на macOS 27.0.1 в сценариях через API: отдельные и объединённые области, результаты в телах и компонентах, вычитание, разделение исходного тела, редактирование, пересчёт и повторное открытие F3D. Это частичная нативная проверка; полная интерактивная приёмка не завершена.

Нативная приёмка Autodesk Fusion на Windows не проводилась. Задание Windows в CI проверяет тесты Python, метаданные и сборку, но не запускает Fusion.
