# Security policy

**English** · [Русский](SECURITY.ru.md)

## Supported versions

There is no stable release or guaranteed security-support window yet. Report suspected vulnerabilities in the current development version. After the first stable release, this section will identify supported release lines explicitly.

## Report privately

Use the repository's **Security → Report a vulnerability** form if private vulnerability reporting is enabled. If it is unavailable, open an issue requesting a private reporting channel **without including exploit details, secrets or confidential models**. A maintainer will arrange an appropriate channel. No public email address or response-time guarantee is currently designated.

Include the affected version or commit, Fusion and OS versions, prerequisites, reproduction steps, impact and any proposed mitigation. Share only files you are authorized to disclose. Coordinate disclosure while the report is investigated.

## Scope

Report vulnerabilities in Ejix source, packaging, installation guidance or project automation. Report vulnerabilities in Fusion or other third-party software to the respective vendor. Ordinary modeling and UX errors belong in a bug report unless they have a demonstrated security impact.
